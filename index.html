Cara install aplikasi ke Layar Utama via Safari

1

Pastikan Anda membuka website ini menggunakan browser bawaan Safari.

2

Ketuk tombol Bagikan (Share) pada bilah menu di bawah layar.

3

Gulir ke bawah dan pilih opsi "Tambah ke Layar Utama" (Add to Home Screen) .

4

Ketuk tombol "Tambah" (Add) di pojok kanan atas. Aplikasi KeuanganKu akan langsung terpasang di Homescreen Anda!
